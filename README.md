# codexeyes 原生 macOS 桌面组件

主入口是 `app/codexeyes.app`，安装后位于系统“应用程序”文件夹。这是一个 SwiftUI/AppKit 原生应用：它以固定尺寸的桌面面板显示在右上角，可拖动并记住位置，并提供菜单栏图标。登录后会自动显示，加入所有 Spaces，使用桌面层级与其他插件共存。运行时不依赖浏览器或 WebView。

组件直接读取本机 `~/.codex/sessions/**/*.jsonl` 中由 Codex CLI 写入的 `rate_limits` 和 token 记录，显示真实周期百分比、重置时间和输入/输出 tokens。账号姓名、邮箱和头像缩写从 `~/.codex/auth.json` 的登录凭据读取。

日志文件变化时会立即刷新，同时保留每 30 秒一次的兜底检查；锁屏期间暂停高频读取。额度达到 80% 或 95% 时，进度条和环形图会切换为预警色，文字保持白色。

悬停在用量区域可查看 5 小时和 7 天窗口详情，点击用量区域可复制摘要；账号凭据提供头像地址时会优先显示真实头像。

## 隐私

用量和账号信息只在本机读取；应用不会将用量、账号姓名或邮箱上传到本项目或其他服务。若本机登录凭据提供头像地址，应用仅按该地址加载头像。仓库不包含任何登录凭据、会话日志、账号姓名、邮箱或本机路径。

## 开源运行

```bash
cd native
./build.sh
./install.sh
```

需要 macOS 13 或更高版本。应用包会安装到 `/Applications/codexeyes.app`，桌面图标不会出现在桌面上。
